## 🚀 PANDUAN INSTALASI (PTERODACTYL / VPS)

1. Upload seluruh file ke File Manager server Pterodactyl / VPS Anda.
2. Buka file `config.js`, lalu masukkan Kunci Lisensi Anda:
   ```javascript
   licenseKey: "RVO-XXXX-XXXX-XXXX",
   ```
3. Jalankan bot:
   ```bash
   npm install
   npm start
   ```
4. Masukkan nomor WhatsApp Anda di terminal saat diminta untuk mendapatkan Pairing Code 8 digit.
5. Masukkan kode di WhatsApp HP: **Perangkat Tertaut > Tautkan dengan nomor telepon saja**.
6. Selesai! Bot siap bekerja mengamankan seluruh media sekali lihat Anda.
